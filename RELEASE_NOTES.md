# mpv_tc — mpv с SMPTE-таймкодом и выводом на Blackmagic DeckLink

Сборка mpv 0.41.0 для Windows (64 бит) и macOS (Apple Silicon) с доработками:

- **SMPTE-таймкод** `HH:MM:SS:FF` (drop-frame `HH:MM:SS;FF` для 29.97/59.94) поверх видео
  и вместо текущего времени в панели управления (OSC).
- **LUT-ы** из меню mpv: Sony S-Log3 / S-Log2, ARRI LogC3 / LogC4, Blackmagic Gen 5 /
  DaVinci Intermediate → Rec.709 BT.1886 в комплекте, можно добавить свои. Считаются на
  видеокарте; при включённом выводе на DeckLink — на процессоре, чтобы попасть и на карту.
- **Вывод на карты Blackmagic DeckLink / UltraStudio**: окно mpv работает как обычно,
  а на карту параллельно идёт чистая картинка без OSD и субтитров. Включается из меню mpv.

| Файл / папка | Что это |

| `mpv.exe`, `mpv.com`, `*.dll` (Windows) / `mpv.app` (macOS) | mpv 0.41.0 с выводом на DeckLink и таймкодом в панели управления |
| `scripts/smpte_timecode.lua` | таймкод поверх видео |
| `scripts/luts.lua`, `luts/` | выбор LUT из меню и набор LUT-ов |

В macOS-сборке `scripts`, `script-opts` и `luts` лежат внутри `mpv.app/Contents/Resources`.

## Установка

Ничего копировать не нужно: mpv находит скрипты и LUT-ы рядом с `mpv.exe` (или внутри
`mpv.app`) сам, таймкод в панели управления встроен. Свои настройки — как обычно в
`%APPDATA%\mpv\` (Windows) или `~/.config/mpv/` (macOS): свой `mpv.conf`, `script-opts\*.conf`,
свои LUT-ы. С папкой `portable_config` рядом с `mpv.exe` (или `--config-dir`, `MPV_HOME`) mpv не
читает папки рядом с `mpv.exe` — скопируйте `scripts` и `luts` туда.

- **Windows:** распакуйте архив в любую папку и запускайте `mpv.exe`.
- **macOS:** перенесите `mpv.app` в «Программы» и перед первым запуском выполните в Терминале
  `xattr -dr com.apple.quarantine /Applications/mpv.app` (приложение не нотаризовано Apple).
  Запуск из Терминала с логом: `MPVBUNDLE=true /Applications/mpv.app/Contents/MacOS/mpv
  --player-operation-mode=cplayer -v файл` (иначе лог пишется только в `~/Library/Logs/mpv.log`).
- Таймкод MOV/MP4 и MXF mpv читает сам; для остальных форматов нужен `ffprobe`:
  Windows — `ffprobe` в `PATH`, macOS — `brew install ffmpeg`.

**Обновление с прошлого релиза:** удалите скопированные вручную `smpte_timecode.lua`,
`luts.lua` и `osc.lua` из папки `scripts` в настройках mpv и строку `osc=no` из `mpv.conf`
(если добавляли её для этого): встроенные скрипты загружаются первыми, а старые копии работали бы
вместе с ними. Из папки `luts` в настройках удалите скопированные папки `Sony`, `ARRI`,
`Blackmagic` (оставьте только свои LUT-ы): копии там используются вместо встроенных, а LUT
S-Log2 изменился. Не переименовывайте скрипты — переименованные копии не работают.

## Вывод на DeckLink

Нужен установленный **Blackmagic Desktop Video 12.0 или новее**.

1. Откройте меню mpv: кнопка ☰ в панели управления, `Ctrl+P` или `g`, затем `m`.
2. **DeckLink output** → выберите карту (или **Auto** — первая карта с выходом).
3. Выбор запоминается и включается при следующем запуске. **Off** в том же меню — выключить.
4. **Sync audio to DeckLink: on** — звук задерживается на задержку карты и совпадает
   с картинкой на карте (окно при этом чуть опережает звук). Тоже запоминается.
   Остаточную разницу (например, задержку самого монитора) подстройте `audio-delay`.

Режим выхода выбирается автоматически по частоте кадров и размеру видео
(например, 25p → 1080p25, 23.976 → 1080p23.98, 50p 720 → 720p50); видео другого размера
вписывается с чёрными полями.

Дополнительные опции (в `mpv.conf` или в командной строке):

| Опция | Описание |
|---|---|
| `decklink-mirror=<карта>` | `auto`, номер с нуля (0 — первая карта) или имя карты; пусто — выключено. Если задана, выбор из меню не применяется |
| `decklink-mode=<режим>` | `auto` или конкретный режим: `1080p25`, `1080i50`, `2160p25`, код `Hp25`. Список — `mpv.com -v` (macOS: `mpv -v`) |
| `decklink-delay=<сек>` | дополнительная задержка вывода, если на карте повторяются или пропадают кадры |
| `decklink-audio-sync=yes` | синхронизировать звук с картой (то же, что пункт меню) |

Особенности:

- Карта показывает кадр примерно на 3,5 кадра плюс `decklink-delay` позже окна (у карты свой
  тактовый генератор). `decklink-delay` можно менять на ходу, вывод не перезапускается.
- HDR-видео выводится на карту без тональной компрессии (света обрезаются).
- Звук идёт через звуковую карту компьютера; на DeckLink выводится только видео, 8 бит 4:2:2.
- При аппаратном декодировании кадры копируются из видеопамяти; при проблемах — `hwdec=auto-copy`.
- На 4K-материале при подёргиваниях на выходе карты помогает `zimg-threads=4`.

## LUT-ы

Меню mpv → **LUT** → папка (Sony, ARRI, Blackmagic) → LUT; **Off** — выключить. Выбор
запоминается. В окне LUT считается на видеокарте; пока включён вывод на DeckLink — на
процессоре, чтобы попасть и на карту (это тяжелее, особенно в 4K).

Свои LUT-ы (`.cube` 3D/1D, `.3dl`, `.dat`, `.m3d`, `.csp`) кладите в папку `luts` в настройках
mpv (`%APPDATA%\mpv\luts\`, `~/.config/mpv/luts/`) — они появятся в меню рядом со
встроенными; каждая подпапка — подменю. Вход LUT — видеоуровни, растянутые в 0–1, как в DaVinci
Resolve, так что LUT-ы производителей для Resolve подходят как есть (в том числе с
`LUT_3D_INPUT_RANGE 0 1`). Нечитаемый LUT и `.cube` с входным диапазоном не 0–1 не
применяются — появится сообщение; запомненный LUT, который не загрузился, выключается. Свой `--lut`
(калибровка монитора) заменяется, пока включён LUT из меню, и возвращается при **Off**.

LUT-ы в комплекте — технические преобразования по опубликованным формулам кривых и гамутов
с нейтральной кривой (18% серого → 40%); это не официальные LUT-ы производителей.

## Управление таймкодом

| Действие | Как |
|---|---|
| Таймкод поверх видео вкл/выкл | `Ctrl+T` или меню → **Timecode overlay**; запоминается |
| Таймкод / время / время с мс в панели | клик по таймкоду в панели |
| Задать стартовый таймкод | `script-message-to smpte_timecode set-start 01:00:00:00`; drop-frame — в кавычках: `set-start "01:00:00;00"` |

Стартовый таймкод берётся из файла: метаданные MXF, трек `tmcd` в MOV/MP4 (mpv читает их сам),
для остальных форматов — через ffprobe, иначе `00:00:00:00`. Настройки шрифта, размера, положения и цвета —
в `script-opts/smpte_timecode.conf` в папке настроек mpv.

Исходники и патчи к mpv: <https://github.com/Velich2/mpv_tc>
